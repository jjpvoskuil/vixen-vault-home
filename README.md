# Vixen Vault launcher

A one-page home-screen launcher for Gigi's Vixen Vault (Streamlit Community Cloud can't set its own
home-screen icon). Contains no passwords or keys: the app address and sign-in token are handed over
once via a setup link from the app and kept only in the phone's browser storage.

Publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
